How I build

Small, readable JavaScript — no framework where none is needed.

State in plain objects, rendering from data, and CSV in and out so the data always stays portable. Example — the workflow stage logic from SolutionQs:

workflow.js
// 12-stage workflow: a package advances one stage at a time
const STAGES = ["Enquiry", "Quoted", "Compared", "Ordered", "Delivered"];

function nextStage(pkg) {
  const i = STAGES.indexOf(pkg.stage);
  if (i < STAGES.length - 1) pkg.stage = STAGES[i + 1];
  return pkg;
}
  • Data stays portable — CSV in, CSV out, nothing locked in.
  • Works offline in the browser — no server to keep alive.
  • Source code public on GitHub, so anyone can read how it works.
